# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes **3,900 customer transactions** to understand purchasing patterns, customer segments, product performance, subscription behavior, and revenue trends. The project demonstrates an end-to-end data analytics workflow using **Python, PostgreSQL/SQL, and Power BI**, transforming raw transactional data into actionable business insights.

## Objectives

* Analyze customer purchasing and spending patterns.
* Identify high-value customers and customer segments.
* Evaluate product performance, ratings, discounts, and shipping preferences.
* Compare subscribers and non-subscribers based on spending and revenue.
* Identify repeat buyers and understand subscription behavior.
* Build an interactive Power BI dashboard for business reporting.

## Tools & Technologies

* **Python:** Pandas, Data Cleaning, EDA, Feature Engineering
* **Database:** PostgreSQL
* **Query Language:** SQL
* **Visualization & BI:** Power BI
* **Data Analysis:** Exploratory Data Analysis, Customer Segmentation, Business Analysis

## Project Workflow

### 1. Data Cleaning & Preparation — Python

The dataset was loaded and analyzed using Python and Pandas. The preprocessing included:

* Dataset exploration and statistical analysis.
* Handling missing values in the `review_rating` column using category-wise median imputation.
* Standardizing column names using snake_case.
* Creating an `age_group` feature by categorizing customer ages.
* Creating a `purchase_frequency_days` feature.
* Checking data consistency and removing redundant information.
* Loading the cleaned dataset into PostgreSQL for further SQL analysis.

### 2. Business Analysis — SQL

PostgreSQL was used to answer key business questions, including:

* Revenue generated by gender.
* High-spending customers who used discounts.
* Top-rated products.
* Average purchase amount by shipping type.
* Subscriber vs. non-subscriber spending and revenue.
* Products with the highest percentage of discounted purchases.
* Customer segmentation into **New, Returning, and Loyal** customers.
* Top products within each category.
* Relationship between repeat purchases and subscriptions.
* Revenue contribution across different age groups.

### 3. Power BI Dashboard

An interactive **Customer Behavior Dashboard** was developed in Power BI to present the analysis visually.

The dashboard includes:

* Total customers
* Average purchase amount
* Average review rating
* Subscription status
* Revenue by category
* Sales by category
* Revenue by age group
* Sales by age group
* Interactive filters for customer and purchase attributes

### 4. Business Insights

The analysis generated insights that can support:

* **Subscription Growth:** Promote exclusive benefits to increase subscriptions.
* **Customer Loyalty:** Reward repeat buyers and encourage movement toward the Loyal segment.
* **Discount Strategy:** Evaluate discounts while maintaining healthy margins.
* **Product Strategy:** Promote highly rated and best-selling products.
* **Targeted Marketing:** Focus marketing efforts on high-revenue customer groups and relevant purchasing behaviors.
